# 🌐 Desafio API

Este repositório contém a solução para o **desafio de implementação de API**, onde uma API foi criada para demonstrar o processo de interação com dados e responder a requisições HTTP.

## 📌 Sobre o Projeto

O projeto envolve a criação de uma **API simples** com o objetivo de manipular dados (como adicionar, editar, excluir ou listar informações). Ele pode servir como base para o desenvolvimento de APIs mais complexas, podendo ser facilmente integrado a diferentes sistemas e front-ends.

## ⚙️ Funcionalidades

- 🚀 **GET**: Recuperar dados de um banco ou armazenamento
- ➕ **POST**: Adicionar novos dados à API
- ✏️ **PUT/PATCH**: Atualizar dados existentes
- ❌ **DELETE**: Remover dados
- 🧑‍💻 **Interação com estrutura de dados simples**

## 🛠 Tecnologias Utilizadas

- **Node.js** (para a criação da API)
- **Express** (para gerenciar rotas e requisições)
- **JSON** (formato de dados utilizado para comunicação)
